<h1 align="center">🚀 LangChain Prompts - One of the Modular Components</h1>

<p align="center">
Learn and Implement Prompt Templates using LangChain and Python
</p>

<hr>

<h2>📌 About The Project</h2>

<p>
This project demonstrates how Prompt Templates work in LangChain using Python.
It focuses on reusable prompt engineering techniques and modular prompt systems.
</p>

<p>
The project is based on a detailed LangChain tutorial and helps beginners understand
how prompts interact with Large Language Models (LLMs).
</p>

<hr>

<h2>🛠️ Technologies Used</h2>

<ul>
  <li>Python</li>
  <li>LangChain</li>
  <li>OpenAI API</li>
  <li>Prompt Templates</li>
  <li>Environment Variables (.env)</li>
</ul>

<h2>⚙️ Installation</h2>

<pre>
git clone https://github.com/Ashuto321/LangChain_Prompts_one_of_the_Modular_Components.git

cd LangChain_Prompts_one_of_the_Modular_Components

pip install -r requirements.txt
</pre>

<hr>

<h2>🔑 Environment Variables</h2>

<p>Create a <code>.env</code> file and add your API key:</p>

<pre>
OPENAI_API_KEY=your_api_key_here
</pre>

<hr>

<h2>▶️ Run The Project</h2>

<pre>
python prompts_interface.py
</pre>
